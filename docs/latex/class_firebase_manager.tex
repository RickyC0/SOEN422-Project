\doxysubsection{Detailed Description}
Handles all Cloud Connectivity for the IoT \doxylink{class_plant}{Plant} System. 


\begin{DoxyItemize}
\item Responsibilities\+:
\end{DoxyItemize}
\begin{DoxyEnumerate}
\item Managing Wi-\/\+Fi and Firebase Authentication.
\item Pushing sensor telemetry (JSON) to the Realtime Database.
\item Listening for remote commands (Pump/\+Light) from the Web Dashboard.
\end{DoxyEnumerate}
\begin{DoxyItemize}
\item Note\+: Uses dynamic memory allocation (new/pointers) to prevent stack overflow crashes during ESP32 boot. 
\end{DoxyItemize}
